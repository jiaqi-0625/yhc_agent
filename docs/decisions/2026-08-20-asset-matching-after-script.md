# 重要产品决策：策略和脚本后精确选材

> 状态：已确认  
> 日期：2026-08-20  
> 影响范围：工作流、Agent 选材、素材快照、分镜

## 决策

正式流程调整为：

```text
营销策略 → 脚本 → 资产匹配 → 分镜 → 视频预览 → 交付
```

- 新建项目只自动装配候选资产池，不做最终选材。
- 策略和脚本确认后，Agent 结合任务类型、时长、已确认内容和资产内置描述词精确选材。
- 车型快照在策略开始时锁定；最终素材快照在资产匹配确认时锁定。
- 分镜逐镜展示引用素材，人物和场景支持人工替换，车型素材不可替换。
- 人工修改优先于 Agent 推荐，修改后按既有确认、版本和下游失效规则处理。

## 实施影响

- WS-108 负责调整既有领域工作流、版本依赖、回退失效和迁移兼容。
- AG-307 负责让 Agent 仅在策略和脚本确认后进行精确选材。
- WS-406、WS-407 在上述调整完成后实现选材与分镜交互。
- WS-403 的单页新建项目和自动创建首条任务不受影响，继续等待用户评审。

本决策取代 WS-101 中“策略 → 资产匹配 → 脚本”的旧顺序。
