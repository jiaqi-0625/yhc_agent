# 待确认技术决策

这些项目尚未定案，代码保持端口/适配器可替换，不把临时选择伪装成生产结论。

模型与资源的当前推荐、成本口径和联合确认栏见工作区根目录的 `P0-02模型与基础资源确认记录.md`。

| 决策 | 当前约束 | 下一步验证 |
|---|---|---|
| 主文本模型与备用模型 | 必须支持 Pi `Model`/`StreamFn` 注入；自动化测试不得产生真实费用 | 用真实中文汽车广告样例评估事实遵循、工具调用、延迟与成本 |
| 数据库 | 已决定使用 PostgreSQL；见 [ADR-001](./adr-001-postgresql-persistence.md) | WS-308 完成在线权威 Store、显式迁移与真实 PostgreSQL 验收；WS-307 仅作为旧作品显式迁移路径 |
| 队列 | 生成任务需支持幂等、重试、取消、超时、死信和成本记账 | 在视频生成纵切前比较托管队列与 Redis 队列 |
| 对象存储 | 原始素材、快照引用、生成物必须版本化并支持短期签名访问 | 验证区域、生命周期、内容哈希和 CDN 策略 |
| 部署平台 | Node.js >=22.19；需要密钥管理、结构化日志、健康检查和滚动发布 | 完成 API + worker 原型后再做容量与成本对比 |
| 车型数据源 | 官方性、版本号、有效期与证据链优先于覆盖量 | 与业务方确认固定卖点、扩展卖点和禁用表述的权威来源 |

决定前不得加入生产凭据、真实投放账户、自动审批或广告发布能力。
