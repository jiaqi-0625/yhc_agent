# 萤火虫汽车广告工作区 V2 产品与实施规格

> 状态：已确认
> 确认日期：2026-08-18
> 对标产品：ArcReel
> 本文用途：作为工作区 V2 的产品边界、领域建模、交互设计和验收依据。

## 1. 目标

萤火虫工作区 V2 面向汽车品牌的信息流短视频批量生产。产品对标 ArcReel 的项目组织、阶段化工作流和三栏工作区，但保留萤火虫现有品牌视觉与汽车广告业务约束。

本轮交付不是静态原型，而是：

- 可运行的完整桌面端前端体验；
- 由后端状态机驱动的真实业务 API；
- 真实执行的账号、品牌、项目、任务、预算和审批策略；
- 采用模拟适配器的公司资产库、视频生成和自动剪辑能力；
- 现有作品数据向新层级的迁移。

本产品只生产广告资产，不包含广告发布和媒体投放。

## 2. 核心领域层级

```text
租户
└─ 品牌（最高业务层级，由管理员建立）
   └─ 车型（由管理员维护参数、事实和资产关联）
      └─ 车型批次项目（由获权制作账号创建）
         └─ 视频任务（一个项目包含多条）
            └─ 阶段产物与版本快照
```

### 2.1 品牌与车型

- 管理员负责品牌、车型、车型参数和公司资产关联。
- 车型事实只能来自版本化车型快照，模型生成内容不能成为官方车型事实。
- 车型资产严格绑定车型，不允许跨车型替换。

### 2.2 车型批次项目

- 一个项目只服务一个品牌下的一个车型和一个固定画幅。
- 同一车型可以建立多个项目，以支持不同画幅、风格或制作批次。
- 项目名称格式为：`品牌 + 车型 + 画幅 + 自定义批次名`。
- 品牌、车型和画幅部分由系统生成且不可编辑；制作账号只填写批次名。
- 项目级锁定：车型、可用资产池、视觉风格、画幅。
- 发布平台不是项目配置，只作为视频任务标签。

### 2.3 视频任务

- 一个项目包含同车型的一批视频任务，共享车型快照来源和项目资产池。
- 任务级配置包括营销主题、受众、脚本入口、时长和发布平台标签。
- 发布平台标签不改变脚本、画幅、时长或生成规则；一条任务可以标记多个平台。
- 每条任务具有独立负责人、阶段状态、预算消耗、产物版本和确认记录。

## 3. 角色与权限

### 3.1 管理员

管理员可以：

- 建立和维护品牌；
- 建立和维护车型及其版本化事实；
- 将公司资产关联到车型；
- 授予账号品牌与车型项目访问权；
- 配置账号额度；
- 查看管理范围内的项目与任务。

### 3.2 制作账号

获得相应品牌和车型权限后，制作账号可以：

- 创建车型批次项目；
- 在项目内创建视频任务；
- 成为任务负责人并推进工作流；
- 确认各阶段产物；
- 在权限允许时接管其他任务。

### 3.3 两级授权与任务独占

- 第一层：账号获得车型项目访问权。
- 第二层：具体视频任务分配一名负责人。
- 其他项目成员可查看任务并执行接管；同一时刻只能有一名负责人操作任务。
- 身份、租户、品牌、项目和任务范围必须从服务端会话解析，不能信任模型或客户端提交的身份字段。

### 3.4 本轮账号演示

- 提供开发用账号切换器，模拟管理员和多个制作账号。
- 后端仍执行真实权限校验，账号切换器不能绕过会话范围。
- 本轮不实现生产级用户名密码登录。

## 4. 新建项目向导

采用与 ArcReel 类似的三步向导，但第一步以车型为业务主键。

### Step 1：选择品牌与车型

- 只展示当前账号获权的品牌和车型。
- 车型由管理员维护，不允许制作账号自由创建。
- 确定车型后才允许进入后续参数与资产配置。

### Step 2：确认资产包

- 自动加载管理员为车型配置的推荐资产包。
- 车型资产不可替换。
- 人物和场景默认使用推荐资产，但允许从公司资产库替换。
- 确认后的选择形成项目可用资产池。

### Step 3：视觉风格与画幅

- 默认继承管理员维护的品牌视觉预设。
- 制作账号可以追加自定义风格提示词。
- 画幅锁定在项目级。
- 账号填写自定义批次名后创建项目。

## 5. 资产库规则

### 5.1 公司资产库

本轮定义统一资产接口、版本化数据模型和模拟适配器，至少覆盖：

- 车型及车型参考图；
- 人物形象；
- 场景；
- 品牌视觉风格；
- 后续可扩展的道具、音频和模板。

管理中心可以浏览、筛选和关联模拟资产。公司资产内容在萤火虫内只读；未来由公司资产库负责新增、编辑和删除。

### 5.2 版本策略

- 项目资产池始终展示公司资产库中的最新版本。
- 每条视频在进入营销策略阶段时锁定车型与素材快照。
- 公司资产更新只影响之后开始策划的新任务，不修改制作中的任务。
- 已锁定快照必须可追溯到资产 ID、版本和来源。

### 5.3 脚本阶段补充资产

- 若已确认资产不足，Agent 可以从公司资产库补充推荐项。
- 补充项必须由负责人确认后加入当前任务快照。
- 同时支持负责人本地上传素材。

### 5.4 本地上传

- 本地上传素材进入当前车型项目的临时资产池，项目成员可以复用。
- 临时资产不自动进入公司资产库。
- 使用前必须检查格式、尺寸和重复项，并记录来源与版权声明。
- 异常素材进入人工处理，不得静默用于生成。

## 6. 视频制作工作流

每条视频任务采用以下主线：

```text
营销策略
  → 资产匹配
  → 脚本
  → 分镜
  → 视频预览
  → 交付
```

### 6.1 任务入口

支持两种入口：

1. 智能策划：输入营销目标、卖点和受众，由 Agent 生成策略与脚本。
2. 已有脚本：提交完整脚本，仍需经过资产匹配、事实校验和后续确认。

### 6.2 人工确认

- 每个阶段都必须由任务负责人确认后才能进入下一阶段。
- Agent 可以请求确认，但不能批准自己的产物。
- 状态变更和高消耗操作必须通过明确的操作卡片由负责人点击执行。
- 人工编辑、锁定字段和确认结果始终优先于模型输出。

### 6.3 版本与回退

- 每次阶段确认创建不可变版本快照。
- 允许负责人回退到历史版本。
- 回退后，所有依赖该版本的下游产物自动标记为失效，必须重新生成并再次确认。
- 聊天记录不是业务状态或版本记录的来源。

## 7. 并发、负责人和成本

- 单个账号同一时间只能运行一条高消耗视频制作任务。
- 不同账号可以各自运行一条任务。
- 人工确认等待不占用运行并发槽位。
- 每个账号配置独立额度。
- 视频生成、自动剪辑等高消耗操作执行前必须展示预估消耗。
- 额度不足时，后端必须拒绝执行；不能只在前端禁用按钮。

## 8. 工作区信息架构

### 8.1 默认首页

制作账号登录后进入项目库：

- 按品牌和车型浏览有权访问的项目；
- 突出展示“我的进行中任务”；
- 支持项目搜索、状态筛选和最近活动排序；
- 管理员额外拥有管理中心入口。

### 8.2 三栏项目工作区

```text
顶部：策划 / 资产 / 分镜 / 制作 / 交付（功能模块）
左侧：项目概览、资产池、视频任务列表及任务状态
中间：当前模块与当前任务的主要操作区
右侧：萤火虫 Agent、计划、操作卡片和上下文
```

- 顶部导航表示工作区功能模块，不代表整个项目的统一进度。
- 每条视频任务独立显示其工作流进度。
- 切换视频任务时，中间工作区和右侧 Agent 上下文必须同步切换。
- Agent 会话必须绑定当前任务，不得跨任务泄漏上下文。

### 8.3 视觉与响应式

- 保留萤火虫现有品牌色和汽车广告专业气质。
- 借鉴 ArcReel 的信息层级、紧凑工具栏、阶段导航和可调整 Agent 面板。
- 不复制 ArcReel 品牌、文案或影视题材视觉。
- 桌面端优先，重点适配 1280–1920px。
- 小屏可以提供不支持完整制作流程的提示，本轮不承诺完整移动端体验。

## 9. Agent 交互边界

- Agent 以“建议 + 操作卡片”为主要交互模式。
- Agent 可以分析上下文、生成草稿、推荐资产、解释风险和发起操作请求。
- Agent 不得自行确认阶段、修改权限、调整额度或绕过预算。
- 生产 Agent 只注册领域工具，不得暴露 shell、文件系统、SQL、任意 HTTP 或浏览器工具。
- 所有外部模型输出必须通过版本化 schema 校验后才能持久化。

## 10. 交付与自动剪辑

一条视频任务完成后，交付包包括：

- 成片 MP4；
- 字幕；
- 最终脚本；
- 分镜；
- 使用素材清单与版本；
- 可继续编辑的剪映草稿。

本轮定义自动剪辑任务接口、状态机和模拟适配器，并在交付页提供“生成剪映草稿”入口。后续真实自动剪辑工具通过适配器接入，不改变工作流契约。

## 11. 管理中心

本轮管理中心至少包含：

- 品牌管理；
- 车型及车型事实版本管理；
- 公司资产浏览、筛选与车型关联；
- 账号品牌/项目授权；
- 账号额度配置；
- 任务与消耗概览。

公司级资产本身保持只读。本地临时资产仅在对应车型项目中管理。

## 12. 工程实施要求

### 12.1 真实实现

- 品牌、车型项目、视频任务和阶段产物的版本化 schema；
- 后端状态机、revision、审批、回退和下游失效规则；
- 品牌、项目、任务负责人和额度策略；
- 账号级运行锁；
- 三步新建项目 API 与 UI；
- 项目库、三栏工作区和管理中心；
- 现有作品迁移。

### 12.2 模拟适配器

- 公司资产库；
- 开发账号身份源。

模拟适配器必须实现与未来真实供应商相同的领域端口，不得把模拟数据结构直接泄漏到 UI 或状态机。

视频生成当前只预留目标为 Seedance 2.5 的 Provider 接口，不实现 Mock 或真实适配器。自动剪辑当前只预留供应商无关的 Provider 接口，后续接入自动化剪辑工具；接口存在不代表能力已可执行。两类真实调用都必须继续经过服务端任务权限、revision、账号运行锁、成本估算和额度结算边界。

### 12.3 现有数据迁移

现有单条“广告作品”迁移为：

```text
示例品牌
└─ 示例车型项目
   └─ 原广告作品对应的视频任务
```

迁移应保留：

- 车型快照；
- 当前工作流状态；
- 策略版本；
- 人工修改与锁定；
- 审批记录；
- revision。

## 13. 验收标准

本轮完成时，至少能够演示：

1. 管理员建立品牌、车型，关联模拟公司资产并授权账号。
2. 制作账号通过三步向导建立车型批次项目。
3. 项目自动加载推荐资产，允许替换人物/场景并上传临时素材。
4. 同一项目创建多条视频任务，并为任务分配或接管负责人。
5. 任务按既定主线推进，在每个确认点暂停。
6. 回退历史版本后，下游产物正确失效。
7. 同账号第二条高消耗任务被后端拒绝，不同账号可分别运行。
8. 额度不足时高消耗操作被后端拒绝。
9. Agent 只能提出操作卡片，不能代替用户确认。
10. 交付页可以通过模拟适配器创建自动剪辑任务并展示状态。
11. 现有广告作品迁移后仍可访问其策略和历史记录。
12. `npm run check` 全部通过，自动化测试不产生真实模型或视频费用。

## 14. 本轮明确不做

- 真实公司资产库接入；
- 真实视频生成供应商接入；
- 真实自动剪辑或剪映工程生成；
- 生产级登录和身份系统；
- 移动端完整制作工作区；
- 广告发布、投放账户或媒体采买。
